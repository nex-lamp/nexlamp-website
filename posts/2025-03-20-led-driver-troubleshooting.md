## 故障分类与排查流程

### 标准排查流程

```
故障现象 → 安全检查 → 外观检查 → 电气测量 → 原因分析 → 解决方案
```

**安全警告：**
> 所有排查操作必须在断电后进行！高压电容可能存有残余电荷，测量前需放电。非专业人员请勿操作！

## 常见故障现象

### 1. 完全无输出

#### 现象描述
- LED灯完全不亮
- 驱动电源指示灯不亮
- 输出端无电压

#### 排查步骤

1. **输入检查**
   - 测量输入端是否有AC电压
   - 检查保险丝是否熔断
   - 检查电源开关和线路连接

2. **外观检查**
   - 检查是否有烧焦气味
   - 查看电容是否鼓包
   - 检查PCB是否有烧蚀痕迹

3. **关键元件测量**
   - 整流桥输出电压（约310V DC）
   - 主控芯片供电电压
   - MOSFET/IGBT是否击穿

#### 常见原因

| 故障点 | 原因 | 解决方案 |
|--------|------|---------|
| 保险丝熔断 | 雷击/浪涌/短路 | 更换保险丝，检查后续电路 |
| 整流桥损坏 | 过压/过流 | 更换整流桥 |
| 电解电容失效 | 老化/高温 | 更换同规格电容 |
| 功率管击穿 | 过压/过热 | 更换功率管，检查驱动电路 |
| 变压器损坏 | 绝缘击穿 | 更换变压器 |

### 2. 输出闪烁

#### 现象描述
- LED灯周期性闪烁
- 亮度不稳定
- 可能伴随嗡嗡声

#### 排查步骤

1. **判断闪烁频率**
   - 50/100Hz闪烁：与工频相关
   - 低频闪烁（<10Hz）：控制环路问题
   - 随机闪烁：接触不良或元件虚焊

2. **负载检查**
   - LED灯珠是否有开路
   - 负载功率是否匹配
   - 输出线是否过长

#### 常见原因

| 故障点 | 原因 | 解决方案 |
|--------|------|---------|
| 输出电容ESR增大 | 电容老化 | 更换输出滤波电容 |
| 反馈环路不稳 | 补偿网络失效 | 检查反馈电阻、电容 |
| 输入电压不稳 | 电网波动 | 增加输入滤波或稳压器 |
| 接触不良 | 接线松动 | 重新紧固接线端子 |
| 负载不匹配 | 功率超出范围 | 更换匹配驱动或调整负载 |

### 3. 过热保护

#### 现象描述
- 驱动电源温度过高
- 工作一段时间后自动关闭
- 外壳烫手（>70℃）

#### 排查步骤

1. **环境温度测量**
   - 安装位置温度是否过高
   - 散热空间是否充足
   - 是否有热源 nearby

2. **负载检查**
   - 实际功率是否超过额定值
   - LED灯珠是否有短路
   - 输出电流是否超标

3. **驱动检查**
   - 效率是否下降
   - 开关频率是否正常
   - 散热片是否松动

#### 常见原因

| 故障点 | 原因 | 解决方案 |
|--------|------|---------|
| 散热不良 | 安装密闭/灰尘堆积 | 改善通风，清理灰尘 |
| 过载运行 | 负载功率过大 | 减小负载或更换大功率驱动 |
| 效率下降 | 元件老化 | 更换老化元件或整体更换 |
| 开关频率异常 | 振荡电路故障 | 检查振荡元件 |
| 热敏电阻失效 | 温度检测不准 | 更换热敏电阻 |

### 4. 调光异常

#### 现象描述
- 调光范围受限
- 调光过程闪烁
- 最低亮度不够低
- 多灯不同步

#### 排查步骤（以0-10V调光为例）

1. **调光信号检查**
   - 测量调光端电压（0-10V）
   - 检查调光器输出是否正常
   - 确认调光线路极性

2. **兼容性检查**
   - 驱动是否支持该调光协议
   - 调光器与驱动是否匹配
   - 调光曲线是否一致

#### 常见原因

| 故障点 | 原因 | 解决方案 |
|--------|------|---------|
| 调光电压不匹配 | 信号源问题 | 检查调光器输出 |
| 调光端悬空 | 未接调光器 | 短接调光端或接调光器 |
| 协议不兼容 | DALI/0-10V混淆 | 确认协议类型 |
| 调光下限过高 | 驱动参数限制 | 更换支持更低亮度的驱动 |
| 线路干扰 | 长距离传输 | 使用屏蔽线或缩短距离 |

## 维护建议

### 日常维护

1. **定期清洁**
   - 每3个月清理散热孔灰尘
   - 保持安装环境干燥
   - 检查接线端子紧固度

2. **运行监测**
   - 记录工作温度
   - 监测输入电压波动
   - 观察输出稳定性

### 预防性维护

| 周期 | 维护内容 |
|------|---------|
| 每月 | 外观检查、温度测量 |
| 每季 | 清洁除尘、接线检查 |
| 每年 | 电气参数测量、效率测试 |
| 每2年 | 电容容量检测、更换老化元件 |

## 工具清单

### 必备工具

- 万用表（电压/电流/电阻）
- 钳形电流表
- 红外测温仪
- 绝缘螺丝刀套装

### 进阶工具

- 示波器（观察波形）
- LCR表（测量电容电感）
- 电子负载（模拟LED特性）
- 耐压测试仪

## 安全注意事项

1. **断电操作**
   - 所有测量前必须断电
   - 等待电容放电（至少5分钟）
   - 使用验电笔确认无电

2. **高压警示**
   - 输入端有220V交流高压
   - 整流后有310V直流高压
   - 部分电路有更高脉冲电压

3. **静电防护**
   - 佩戴防静电手环
   - 在防静电垫工作
   - 避免触摸IC引脚

## 快速诊断表

| 现象 | 优先检查 | 可能原因 |
|------|---------|---------|
| 完全不亮 | 输入电压 | 保险丝、整流桥 |
| 闪烁 | 输出电容 | ESR增大、反馈环路 |
| 过热 | 负载功率 | 过载、散热不良 |
| 调光不灵 | 调光信号 | 协议不匹配、线路问题 |
| 噪声大 | 电感/变压器 | 松动、磁芯间隙 |
| 寿命短 | 工作温度 | 高温、电压不稳 |
