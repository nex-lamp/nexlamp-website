### 踩坑
- **bash heredoc 写长文会被内容里的引号打断**（`unexpected EOF while looking for matching '`），长 Markdown 追加改用 Python `io.open(mode='a')`
- **Write 工具单次内容过大会导致参数丢失**，超长文章要分块写
- **toutiao-ops 编辑器选择器超时 ≠ 页面问题**，先跑 `auth check` 确认登录态，能省大量排查时间
- git push 网络不通时不要死磕重试，先并行跑完其他平台，收尾再回来重试通常就通了（本次前7次失败，第8次成功），不必上 GitHub API 兜底
- **git push 不要挂后台**：本次后台 push 跑了 24分55秒才返回，且带的是 rebase 前的旧 ref，回来报 `! [rejected] non-fast-forward` 虚假告警（前台已推成功，local=remote=5eabd5d）。push 一律前台 `timeout 90 git push`
- rebase 遇 `dist/` add/add 冲突时，`git add` 会被 .gitignore 忽略，必须用 `git add -f`，然后 `GIT_EDITOR=true git rebase --continue`
