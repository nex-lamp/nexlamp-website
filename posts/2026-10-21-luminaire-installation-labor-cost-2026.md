双11的灯陆续到货，装灯这件小事开始出问题。

北京有人装一盏普通吸顶灯，电话里报价80，结账300。重庆一位业主装吊灯，报价单写80，上门说吊顶要加固加400，装完又说缺两个挂板再收120，一盏灯人工到600。

钱不是被手艺吃掉的，是被那张只写了"安装"两个字的报价单吃掉的。

## 报价 80 和 300，中间差的是"加项"

装灯没有一口价，只有"底价 + 加项"。底价是拆旧装新、原孔位不动、手够得着；动到孔位、层高、线路，就出加项。

| 加项 | 常见行情 | 什么情况会碰上 |
|---|---|---|
| 基础安装（吸顶灯） | 60~150 元/盏 | 含基础接线、原孔位打孔 |
| 吊灯 / 水晶灯 | 100~400 元/盏 | 要组装挂件、件数多、费时 |
| 筒灯 / 射灯 | 15~60 元/个 | 数量多可谈打包价 |
| 智能灯（含调试） | 150~300 元/盏 | 要配网、试调光、教使用 |
| 旧灯拆除 | 20~50 元/盏 | 有的平台装新灯含拆旧，先问 |
| 上门费 | 30~50 元 | 部分师傅单收 |
| 顶面开孔 | 30~80 元/个 | 原顶没预留孔 |
| 高空作业 | 层高超 3 米，每超 1 米约 +50 元 | 挑高客厅、楼梯间 |
| 线路检修 / 重新布线 | 50~150 元/次 / 300~800 元 | 老房、线径不够、要移位 |
| 全屋打包（三室一厅） | 300~500 元 | 比单盏便宜，数量多一定要谈 |

最容易被临时加的是开孔和高空，上门前根本看不出来。最容易做出利润的是辅材，挂板、膨胀螺丝不值钱，按件收。

## 三个动作，是 80 变 300 的真正机制

第一个动作，先拆后报价。旧灯拆下来就装不回去了，主动权也没了。正规做法是先看现场、先报价、你点头才动手。

第二个动作，把一件活拆成几个名目：安装、拆旧、加固、挂板各算一笔，单看都不离谱，加起来翻倍。

第三个动作，拿"线路老化"当理由。拆之前就说，八成是话术；总跳闸、端子发烫，才值得查。

## 智能灯为什么天然贵一档：钱在"调"不在"装"

装和调是两件事。装是放线、接线、固定；调是配网、分组、场景、亮度。干了二十年强电的师傅，压端子查线路闭着眼都会，让他配网关、设场景，他卡住。

有电工接酒店走廊的智能照明，装完调不明白，手册几十页看两页就放下，最后花800块从外地请人干了半天。

| 步骤 | 普通灯 | 智能灯 |
|---|---|---|
| 接线 | 火线零线接上就亮 | 同上，但多了驱动的位置要想 |
| 通电 | 亮不亮一眼看得出 | 亮只是第一步，还要看有没有频闪、最低亮度对不对 |
| 联网 | 无 | 配网、分组、起名字 |
| 场景 | 无 | 开关要绑灯，场景要设，家里人要学会用 |
| 交付 | 装完就走 | 得当场调完、演示一遍再走 |

![装和调是两件事](../../images/blog-install-labor-2026-install-vs-commission.svg)

我这边常接到这种电话，客户说"你们的电源坏了"。我让他先拍张接线端子照片，一看就清楚：端子没插到底，线皮压在里头。也见过驱动塞在吊顶夹层里热保护的，还有配网失败、2.4G和5G混着。

查故障分三层：通电亮不亮、能不能连上、调光顺不顺。别一上来就怀疑电源。

## 装之前，五句话把价锁死

- "拆旧灯算不算在安装费里？"
- "顶上有预留孔吗？没有的话开一个多少钱？"
- "我家层高多少，超3米要不要加高空费，加多少？"
- "挂板、膨胀螺丝、接线端子是你带还是我买？你带的一件多少钱？"
- "智能灯要配网、要调最低亮度和缓开缓灭，这一步含在报价里吗？调不好算谁的？"

电话里就敢报一口价、不看现场就说"全包"的，多半先上门再找理由。敢让你先看清单再定工的反而靠谱。

## 哪些活自己能干，哪些别碰

层高3米以内、有稳的梯子、顶面是石膏板或铝扣板、孔位现成，吸顶灯和筒灯自己换没问题。前提是断电、验电、拍照留底。

要新开孔别自己干。石膏板容易崩边，铝扣板要专用开孔器，开歪了补救更贵。

水晶灯、多层吊灯要组装挂件、要往混凝土里打膨胀螺栓，找师傅。掉下来不是钱的事。

全屋几十个筒灯射灯别一个个算，直接谈打包，三室一厅300~500能谈下来。

## 最后三句

加项不可怕，可怕的是加项不在纸上。

智能灯的钱，一半花在装，一半花在调。只肯装不肯调的，等于买了个普通灯。

装完当天就把场景跑一遍，别等住进去才发现有个开关是摆设。

## 三个最常被问到的

**Q：网购页面写"包安装"，为什么师傅上门还要收钱？**

A：页面上的"包安装"只包最基础一档：原孔位、吸顶灯、手够得着。拆旧、开孔、高空、辅材、调试都在外头，先看清"不含"那一栏。

**Q：师傅说线路老化必须换线，怎么判断是真话还是话术？**

A：看什么时候说的。拆之前就说，八成是话术。真该换线的迹象很具体：总跳闸、端子发烫、线皮一掰就碎、老房子还是铝线。指不出来就别换。

**Q：智能灯装完App连不上，是灯的问题还是装的问题？**

A：分三层查。灯亮不亮，亮说明通电没问题；搜不到设备，多半是配网没进对模式，或者2.4G和5G混着；能连上但调光跳变，才轮到驱动和灯珠。
